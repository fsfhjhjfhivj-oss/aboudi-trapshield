# ids-lite (نسخة عربية مختصرة)

إضافة خفيفة **لكشف التسلل وتنبيه مالك الموقع**: قواعد كشف، حساسية قابلة للضبط، حظر مؤقت للعناوين، بانر تحذير للزائر،
سجل نشاط، تخزين دائم، وواجهة API للإدارة. لا تعتمد على أي مكتبات تشغيل (Express مطلوبة فقط كـ peer dependency).

> هذه الإضافة "جهاز إنذار" وليست جدار حماية تطبيقات (WAF) ولا تغني عن التحقق من المدخلات والتحديثات الأمنية وHTTPS.

## البدء السريع
```bash
npm install
npm test
IDS_HMAC_KEY=change-me-please-0123456789 IDS_ADMIN_TOKEN=admin-secret npm start
```
ثم أضف السطر التالي إلى قالب الصفحة لعرض البانر: `<script src="/ids/static/banner.js" defer></script>`

## المراحل الموصى بها للتفعيل
1. `monitor` (تسجيل فقط، وهو الافتراضي) لمدة أسبوع إلى أسبوعين مع مراجعة الأحداث.
2. `warn` لإظهار تنبيه للزائر.
3. `enforce` لتفعيل الحظر المؤقت، بعد إضافة عناوين الإدارة إلى `allowlist_ips`.

## الخصوصية
- العناوين تُخزَّن كبصمة HMAC فقط، والعناوين الخام معطّلة افتراضيًا (وتُمسح بعد 7 أيام إن فعّلتها).
- تُنقَّح كلمات المرور والرموز من الأدلة قبل الحفظ، وتُحذف الأحداث بعد `retention_days` (30 يومًا افتراضيًا).

للتفاصيل الكاملة (واجهات API، الإعدادات، تدوير المفاتيح) راجع `README.md` والمجلد `docs/`.
